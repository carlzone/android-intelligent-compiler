# ADR 0001: M0 compiler architecture

Status: accepted

The prototype compiler core is Rust, its canonical input is a custom validated AIC IR, and its primary executable target is DEX emitted directly by AIC. M0 deliberately has no Java, Kotlin, Gradle, APK, Android UI, or AI path.

The DEX writer owns deterministic indexing, layout, fixups, and integrity calculation. Binary structures are not generated by a model. This boundary keeps the compiler independently testable and makes identical IR and compiler inputs byte-for-byte reproducible.

DEX 035 is selected for the kernel proof because the M0 instruction and metadata subset needs none of the later format additions. Android API levels and a physical reference device remain M1 decisions.
